# SWITH

> **문제 추천부터 코드 이해, 실시간 스터디, 복습까지 하나의 흐름으로 연결하는 AI 기반 알고리즘 스터디 플랫폼**

## 서비스 소개

**SWITH(Study With)**는 알고리즘 스터디 과정에서 반복적으로 발생하는  
**문제 선정의 부담, 코드 이해의 어려움, 체계적인 복습의 부재**를 해결하기 위해 개발한 AI 기반 학습 플랫폼입니다.

스터디원의 solved.ac 풀이 이력을 기반으로 수준에 맞는 문제를 추천하고,  
제출한 코드를 구조와 실행 흐름에 따라 시각화하여 오답 원인을 직관적으로 확인할 수 있도록 지원합니다.

또한 실시간 음성 스터디와 AI 인사이트를 통해 팀원 간 풀이를 비교하고,  
스터디 종료 후에는 학습 내용을 정리한 리포트와 개인별 복습 문제를 제공하여  
**문제 선정 → 풀이 → 토론 → 복습**으로 이어지는 알고리즘 학습 전 과정을 지원합니다.

## 기획 배경

알고리즘 스터디를 진행하면서 다음과 같은 세 가지 문제를 발견했습니다.

1. **문제 선정의 부담**  
   스터디원의 실력과 학습 이력이 서로 달라 모두에게 적절한 문제를 선정하기 어렵습니다.

2. **코드 이해와 디버깅의 어려움**  
   정답 여부만으로는 코드가 어떤 방식으로 동작했는지 파악하기 어렵고, 다른 사람의 풀이를 이해하는 데에도 많은 시간이 필요합니다.

3. **스터디 이후 복습의 부재**  
   스터디에서 나눈 풀이와 피드백이 체계적으로 기록되지 않아 학습 내용이 일회성으로 끝나는 경우가 많습니다.

SWITH는 이러한 문제를 해결하기 위해  
**스터디 전에는 맞춤형 문제 추천**,  
**풀이 중에는 코드 시각화**,  
**스터디 중에는 실시간 협업과 AI 분석**,  
**스터디 후에는 학습 리포트와 복습 추천**을 제공하도록 설계했습니다.

이를 통해 단순히 문제를 함께 푸는 스터디를 넘어,  
**오늘의 풀이가 다음 학습으로 이어지는 지속적인 알고리즘 학습 경험**을 만드는 것을 목표로 합니다.
